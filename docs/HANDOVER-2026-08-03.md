## 5. Known-good state / gotchas

- `tsc --noEmit` clean · `npm run build` compiles · lint clean apart from pre-existing
  unused imports and one pre-existing `<a href="/">` in the assessment page.
- **A green local build does not mean a green deploy.** Two pushes failed on Vercel while
  building fine locally, because `lib/recaptcha.ts` existed on disk but was untracked.
  **Check the deployment after pushing**, not just the local build.
- `globals.css` loads *after* Tailwind at equal specificity — a `display` declaration on a
  class there silently beats `hidden` / `sm:block` utilities. This rendered both
  DisconnectDiagram layouts at once. Breakpoints for such components live in `globals.css`.
- An **inline** `background` on a card beats `.card-lift` and silently kills the hover.
  Featured pricing cards override `--color-bg-card` locally instead.
- Turbopack served stale CSS twice; `rm -rf .next` before trusting a CSS change.
- Structured outputs reject array-length constraints and type-array nullables — use
  `anyOf`, and assert lengths after parse.
- The in-app Browser pane was unreliable all session (hidden pane → stale screenshots,
  scroll not committing, `navigate` timeouts). Verify via computed styles / `curl` when it
  misbehaves, and say so rather than claiming visual confirmation.
